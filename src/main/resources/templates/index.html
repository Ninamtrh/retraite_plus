01 · Le salarié

Identité et date de départ envisagée

Sert aux trimestres pour enfants.
Une retraite prend effet le 1er jour d'un mois. Le simulateur indique si le départ est possible à cette date et compare d'autres dates.

02 · La carrière (relevé année par année)

Une ligne par année et par période. Format : annee;type;revenu;devise;trimestres;points

Aide à la saisie
  • type : SALAIRE, SERVICE_NATIONAL, CHOMAGE, MALADIE, MATERNITE, INVALIDITE, AUTRE.
  • revenu : revenu soumis à cotisation ; devise FRF avant 2002, EUR ensuite (déduite si vide).
  • trimestres : ceux du relevé ; laissez vide pour un calcul automatique (seuil de 150 h de SMIC, 200 h avant 2014). Un écart avec le revenu est signalé.
  • points : points Agirc-Arrco de l'année ; vide = calcul automatique à partir du salaire (à partir de 2021).
  • Plusieurs lignes pour une même année sont additionnées (plusieurs employeurs, période assimilée…). Copier-coller depuis Excel accepté (tabulations).
Fonction publique, indépendants…
Prolonge la carrière jusqu'au départ.
